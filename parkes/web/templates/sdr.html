SDR Network Sharing

Exposes the local SDR over the network via SoapyRemote, so gpredict/gqrx/a laptop-side satdump can use it directly. Mutually exclusive with local app profiles that need the SDR -- only one can hold the physical device at a time. With Auto-manage on, sharing releases automatically for a local app profile that needs the SDR, and resumes once it's free.
