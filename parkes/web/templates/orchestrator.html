Pass Orchestrator

Finds the soonest pass among the satellites below, points the rotator at it, and launches that downlink's "pass"-mode app profile for the duration. Mutually exclusive with SDR Network Sharing (both want the SDR) and, only while actively tracking a pass, manual tracking (both want the rotator).

 

Tracked Satellites

Satellites the Pass Orchestrator watches. Disable an entry to keep its downlink config without deleting it. A downlink's app must be a "pass"-mode profile below. List order is priority: when two passes overlap, or one is continuously visible, the orchestrator prefers whichever is higher in this list.

SatelliteDownlinksPriority

Static Positions

Fixed az/el positions you point the dish at by hand -- never picked up by the Pass Orchestrator's scheduling, only triggered here. "Go" moves the rotator once and, if any downlink below is enabled and has an app, launches that one (first enabled wins, same as Tracked Satellites) -- the app must be a "standalone" profile, since nothing here is pass-triggered.

NameAz / ElDownlinks

Pass Overlaps

Where two tracked satellites' passes would overlap in the next 48 hours. The orchestrator can only track one at a time -- see the priority order above for how it'd decide between them.

App Profiles

A "pass"-mode profile is launched by the Pass Orchestrator when its satellite is in range, and needs {frequency} (alias {down_frequency}) -- plus {up_frequency} if the triggering downlink has an associated uplink set (e.g. a transponder/repeater pair). A "standalone" profile has nothing to do with any satellite -- start/stop it by hand, or set it to auto-repeat. Other placeholders filled in at launch: {output_dir}, {source}, {source_id}, {samplerate}, {timestamp} (fresh per run -- use it in an output path so consecutive runs don't overwrite each other).
