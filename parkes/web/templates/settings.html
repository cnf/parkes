Pass Orchestrator

Rotator (rotctld)

Parkes starts and supervises rotctld itself when "Managed" is on. Model list comes from rotctl -l on this machine's Hamlib install. "Host" is always where this app connects; "Bind address" only matters when Managed is on -- it's what interface the daemon Parkes spawns listens on. Set it to 0.0.0.0 to let other rotctld clients (e.g. gpredict on a laptop) reach it over the LAN while Host stays localhost for Parkes's own connection.

GPS (gpsd)

Off by default -- most setups rely on the system's own gpsd.service, which other things (like chrony) may also use. Only turn "Managed" on for a Pi where Parkes is the sole gpsd consumer. "Host" is always where this app connects; "Bind address" only matters when Managed is on (anything other than localhost tells gpsd to listen on all interfaces, not just loopback).

Connection & Paths

Binary/data-path config -- set via environment variables / devenv.nix, changing these needs a restart.

TLE Sources

Any URL serving a TLE-formatted file (Celestrak group queries, AMSAT, a custom list...). Adding a source only makes its satellites appear on the Satellites page -- assigning them into groups is a separate step there.
